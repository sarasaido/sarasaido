## Featured projects

### [PLANORA · Renovation Vision](https://github.com/sarasaido/planora-renovation-vision)

An AI-assisted renovation concept that turns structured building data into an accessible vision for an existing property. Developed as an independent post-Makerthon extension following the event hosted by the Makerspace at Ruhr University Bochum, with acknowledgement of the A-Team and blixdata collaboration.

### [Timber Truss Bridge Study](https://github.com/sarasaido/timber-truss-bridge-study)

A structural concept study of a timber truss bridge developed with Dlubal RSTAB 8, including modelling, engineering documentation, and visual presentation.

### [Beam Load Visualizer](https://github.com/sarasaido/beam-load-visualizer)

An interactive Java application for visualizing a simply supported beam, applied loads, support reactions, shear force, and bending moment diagrams.
